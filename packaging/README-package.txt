OpenDraw7 for Linux (x86_64)
============================

A paint program in the style of the one from Windows 7.

Try it without installing
    Open this folder in a terminal and run:   ./opendraw7
    (or double-click "opendraw7" in your file manager)

Install it for your user (adds it to the applications menu)
    ./install.sh

Remove it again
    ./uninstall.sh

Needs
    A 64-bit Intel/AMD Linux desktop from roughly 2022 or newer
    (glibc 2.34+: Ubuntu 22.04, Mint 21, Debian 12, Fedora 35 or later).

If the window buttons or dragging misbehave on your desktop, start it with
    ./opendraw7 --native-frame
to use your desktop's own title bar instead of the built-in one.
